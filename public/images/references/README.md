# Reference Company Logos

Place company logo images in this directory. The logos should be:

- **Format**: PNG or SVG (preferred for scalability)
- **Background**: Transparent or white
- **Naming**: Use lowercase with hyphens, matching the filenames in `References.tsx`
- **Size**: Recommended 200-400px width, maintain aspect ratio
- **Style**: High quality, professional logos

## Example filenames:
- `mercedes-benz.png`
- `nissan.png`
- `volvo.png`
- `sony.png`
- `roche.png`
- etc.

If a logo file doesn't exist, the component will display the company name as text instead.
