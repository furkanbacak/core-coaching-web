# Blog Hero Video

Place your `blog-hero.mp4` file directly in the `/public/` folder.

## Video Requirements:

- **Format**: MP4 (H.264 codec recommended)
- **Resolution**: 1920x1080 (Full HD) or 1280x720 (HD)
- **Duration**: 10-30 seconds (will loop automatically)
- **File Size**: Optimize for web (aim for 2-5MB if possible)
- **Content**: Dynamic, engaging, related to thought leadership/blogging
- **Style**: More energetic and dynamic than the main hero video

## Tips:

- Use a video editing tool to compress the video for web
- Consider using dynamic, abstract backgrounds or office/workplace scenes
- The video will be darkened with an overlay for better text readability
- More movement and energy compared to the main hero video
