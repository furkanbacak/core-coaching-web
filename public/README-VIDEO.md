# Hero Video

Place your `hero-video.mp4` file directly in the `/public/` folder.

## Video Requirements:

- **Format**: MP4 (H.264 codec recommended for best browser compatibility)
- **Resolution**: 1920x1080 (Full HD) or 1280x720 (HD)
- **Duration**: 10-30 seconds (will loop automatically)
- **File Size**: Optimize for web (aim for 2-5MB if possible)
- **Content**: Abstract, professional, related to coaching/transformation
- **Style**: Calm, minimal, modern - should complement the text overlay

## Tips:

- Use a video editing tool to compress the video for web
- Consider using a subtle, abstract background (nature, office, abstract patterns)
- Ensure the video doesn't distract from the text content
- The video will be darkened with an overlay for better text readability
